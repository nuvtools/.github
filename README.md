# .github

The organization-level repository of [Nuv Tools](https://github.com/nuvtools).

| Path | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The page shown at [github.com/nuvtools](https://github.com/nuvtools) |
| [`profile/PACKAGES.md`](profile/PACKAGES.md) | Catalog of every package published on nuget.org |
| [`profile/ARCHITECTURE.md`](profile/ARCHITECTURE.md) | How the packages depend on each other and where they fit in an application |

Only public repositories and packages published on nuget.org are listed. When a package is
published or retired, update the catalog and, if its references changed, the diagrams in the
architecture page.
